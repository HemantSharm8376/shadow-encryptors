# shadow-encryptors
AI-powered phishing detection system
SHADOW ENCRYPTORS – AI Phishing Detection System

Problem Statement

On March 11, 2026, CRPF faced a phishing email attack where a single click compromised critical systems.
This highlights a major issue: **phishing is the #1 entry point for cyberattacks**, mainly due to human error and lack of proactive protection.

Solution:- 

We built an "AI-powered phishing detection system" that proactively scans:

1.Emails 📧
2.SMS 📱
3.QR Codes 🔳
4.URLs 🔗
5.Files 📂

The system detects threats "before the user clicks" and provides real-time alerts.


Architecture

1.Input Layer → Email, SMS, QR, URL
2.AI Detection → NLP (BERT), URL Analyzer
3.Threat Intelligence → Google Safe Browsing + VirusTotal
4.AI Risk Engine → ML-based scoring
5.Decision System → Allow / Warn / Block


Tech Stack

1.Python, Dart (Flutter), JavaScript
2.FastAPI, TensorFlow / PyTorch
3.MongoDB, Redis
4.OpenCV, ZBar
5.APIs: Google Safe Browsing, VirusTotal


Key Features

:- Real-time phishing detection
:- AI-based risk scoring
:- QR & URL scanning
:- Background protection
:- Privacy-focused system
:- 6-in-1 threat protection


Impact

1.💰 Prevents financial fraud
2.🧑‍🤝‍🧑 Protects non-technical users
3.🌍 Reduces cybercrime impact
4.🔐 Improves digital safety


Future Scope

1.Browser extension integration
2.Enterprise dashboard
3.Real-time threat sharing network
